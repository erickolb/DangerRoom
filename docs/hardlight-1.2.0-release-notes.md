# Hardlight 1.2.0

**Find a comic by its cover.** Metron now supports image cover search, and so does Danger Room. Open Image Cover Search, choose the maximum hash distance (default 14), photograph the cover, and adjust its rotation or corners. Tap Next to see matching issues and use the familiar collection and Want List controls.

[See cover image search in action](https://erickolb.github.io/DangerRoom/hardlight/cover-image-search/).
