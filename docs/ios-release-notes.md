# Danger Room (Hardlight) v1.0.2 for iOS

First iOS release, build 1, for iPhone and iPad running iOS 17+.

- Native startup and connection settings, device-only Keychain credentials and redirect protection.
- Shared Want List, My Collection, Search Metron, Cover Slideshow and Reading Log, with exact variants, ratings and black bags.
- Local slideshow cache: 180 days, default 300 MB, unlimited option and Flush cache. Playback pauses in the background.

Update the DangerRoom server to β-029 or later and issue a separate device credential for this installation. Download DangerRoom.ipa and verify DangerRoom.ipa.sha256. The IPA has a verified ad-hoc signature; import into SideStore to re-sign for your device. Refresh before signing expires. No App Store release, extensions or camera scanning.
